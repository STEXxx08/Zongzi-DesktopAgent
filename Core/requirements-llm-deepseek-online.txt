# ── 这个环境跑三个服务，每个服务有自己的依赖文件 ─────────────────────────────
#   本文件 = **公共部分**；各服务的专属依赖放在它自己的目录下，你用到哪个就装哪个：

#     服务        实现（Core/config.yaml 的 id）        依赖文件
#     ---------------------------------------------------------------------------
#     llm         deepseek_online/…（在线 API）          Core/llm/deepseek_online/requirements.txt
#     llm-memory  同上（同一套代码，换端口）             （同上）
#     mllm        mllm_online/qwen（阿里云百炼）         Core/mllm/requirements.txt
#     web_search  SearXNG                                Core/web_search/requirements.txt
#
#   安装 = 公共（本文件）+ 你要跑的那几份，例如全都要：
#     conda create -n llm_deepseek_online python=3.11
#     conda activate llm_deepseek_online
#     pip install -r Core/requirements-llm-deepseek-online.txt
#     pip install -r Core/llm/deepseek_online/requirements.txt
#     pip install -r Core/mllm/requirements.txt
#     pip install -r Core/web_search/requirements.txt
#     pip install -e con-datapack-1.11
#
# ── 不在这套环境里的「LLM 路线」──────────────────────────────────────────────
#   Core/llm/ 下还有 ollama 与 6 个本地大模型（chatglm3 / qwen / shisa / yi /
#   glm4 / deepseek）。本地那几条需要 torch + transformers + vllm，**vllm 在
#   Windows 上不可用**，所以它们不装进这个环境；各自目录里的 pyproject.toml 是
